## 7. 推荐使用顺序（配合交接单第五节）

```
第 1 步  补测 P0（Web 端订单操作）
         → webapp-testing + 组合技12-全功能真实数据测试

第 2 步  补测 P1/P2（管理端、移动端剩余 2 页）
         → systematic-debugging（遇到坑时）

第 3 步  代码质量收口
         → code-review-and-quality → lint-and-validate
         → boshi-sql-code-review / database-design（init.sql）
         → 安全三件套：boshi-threat-model-analyst + security-and-hardening + boshi-secret-scanning
         → git-workflow-and-versioning（统一提交规范）

第 4 步  产出论述类材料
         → 组合技9-知识库文档自动化（系统设计章 + 架构图）
         → archify（时序图/状态机图，订单状态机现成的）
         → documentation-and-adrs（设计决策记录）

第 5 步  论文成稿
         → zotero-import（GB/T 7714 文献列表）
         → content-research-writer（文献综述/引言）
         → docx（套学校模板排版）
         → academic-citation-validator（定稿前必跑）

第 6 步  答辩
         → pptx（答辩 PPT，套学校模板）
         → （可选）archify 出图嵌入
```

## 8. 一句话总结

> 289 个技能里，**对毕设真正有价值的是 35 个左右**，其中 `zotero-import`、`academic-citation-validator`、`docx`、`pptx`、`webapp-testing`、`archify`、`systematic-debugging` 这 7 个是"必须用"级别；`组合技9`（写系统设计章）和 `组合技12`（补 P0 测试）是两条最划算的流水线。剩下 250 多个是电商、自媒体、视频类，与本项目无关。
