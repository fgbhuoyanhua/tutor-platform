## 1. 测试概述

### 1.1 测试目的

对「大学生家教服务预约平台」进行系统性功能验证与缺陷修复回归。测试以**开发设计方案 V4 承诺功能 vs 代码现状**的差距审查结果为依据，对发现的 20 项优化点逐条实施、逐条测试，并对测试过程中暴露的真实缺陷进行定位、修复与回归验证。

## 3. 测试方法

1. **接口链路测试**：后端打包后启动（就绪探针 GET /api/subjects），使用 curl.exe 直连接口，脚本内含硬断言（检查 code 与业务结果），失败即输出 [FAIL]。中文参数经 EscapeDataString 编码，请求体写入临时 JSON 文件以 --data-binary 提交。
2. **单元测试**：`mvn test` 运行 JUnit 5 用例（订单状态机、登录限流降级）。
3. **前端校验**：`vue-tsc --noEmit` 类型检查；移动端 TS 文件语法检查 + 引用一致性静态校验。
4. **并发测试**：多进程并发请求同一预约时段，验证唯一索引兜底。
5. **生产配置自检测试**：以 prod profile 分别携带 mock=true、弱密钥、强密钥启动，验证拒绝/放行行为。

## 5. 缺陷修复记录（5 个真实缺陷）

| # | 缺陷现象 | 定位 | 修复方式 | 回归验证 |
|---|---------|------|---------|---------|
| 1 | 评价公开接口 GET /api/evaluations/tutor/{id} 返回 401，前端无法加载评价 | JwtInterceptor 未放行公开 GET | 拦截器放行该公开路径 | 未登录访问返回 200 数据 |
| 2 | 订单「授课中」为死状态：已预约直接跳已完成，无开始授课动作 | OrderDomain 缺少 start 动作、finish 前提错误 | 新增 start（仅老师，已预约→授课中），finish 前提改为授课中 | 正常流转 + 全部非法流转拦截 |
| 3 | 非法/过期 JWT 返回 500 而非 401 | 全局异常未处理 JWT 异常 | GlobalExceptionHandler 增加 ExpiredJwtException / JwtException → 401 | 非法 token、过期 token 均 401 |
| 4 | 手机号/用户名重复注册返回 500，提示泛化 | register 唯一键冲突未捕获 | 显式捕获 uk_phone/uk_username → 400 精确提示 | 同手机号/同用户名/全新注册三场景 |
| 5 | 家教数据重复时应用启动失败（selectOne 抛 TooManyResults） | DataInitializer 用 selectOne 判断且无幂等兜底 | selectOne 前先按 userId 幂等去重，保留最早记录 | 脏数据下正常启动，重复记录被清理 |

## 8. 测试结论

1. 20 项优化全部实施并逐条测试通过，设计文档 V4 承诺的核心功能（评价、收入统计、订单监管、授课中状态、资料/改密、科目管理）全部落地。
2. 测试过程中发现并修复 5 个真实缺陷，其中「JWT 异常返回 500」「DataInitializer 启动崩溃」影响面大，均已回归验证。
3. 安全能力补齐：登录限流、验证码限次、生产配置自检、并发兜底均实测生效。
4. 后端 11 个单元测试全绿，Web 前端类型检查 0 错误。
5. 移动端 .uvue 最终编译依赖 HBuilderX（本机未安装），已通过 TS 语法检查、引用一致性校验，且所调用接口（start/income/评价）均已由后端实测背书。
