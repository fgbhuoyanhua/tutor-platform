## 一、任务概述

在已完成 Web 端消息中心基础上，补齐 uni-app x 移动端消息模块三项功能，并修复私信收发链路中的多处兼容性问题：

1. **删除已读通知**：学生/老师可一键清空所有已读通知（不影响私信）
2. **单条通知已读**：点某条通知才标记该条已读，未读加粗显示
3. **私信收发修复**：修复移动端发消息接口参数错误、聊天页布局、消息方向判断

## 二、执行内容

| # | 内容 | 说明 |
|---|------|------|
| 1 | 后端 deleteRead 接口 | `DELETE /api/messages/read`，删除 toId=uid and isRead=1 and type≠4 的消息（只删通知不删私信） |
| 2 | 后端 markOneRead 接口 | `PUT /api/messages/{id}/read`，单条消息标记已读 |
| 3 | 移动端通知区 UI | 标题旁加"删除已读"按钮；未读通知加粗；点通知调单条已读接口 |
| 4 | 移动端发消息修复 | 参数 `otherId`→`toId`，路径 `/messages/send`→`/messages`（对齐后端 SendMessageDTO） |
| 5 | 聊天页布局修复 | 根节点固定 height:700px，消息区 500px，输入框在底部固定显示 |
| 6 | 消息方向判断 | load 后逐条将 fromId==myId 的结果存入 `m.isMine`，自己发的右侧蓝色，对方左侧白色 |
| 7 | 后端命令行编译 | 解压 Spring Boot fat jar，javac 加 `-parameters` 参数编译后替换 class 回 jar |

## 四、缺陷与问题修复

| # | 现象 | 定位 | 修复 | 回归 |
|---|------|------|------|------|
| 1 | DELETE /read 返回 500 | 旧 jar 无此路由 | javac 编译新类替换 jar | code=200 ✓ |
| 2 | 对话接口 500，日志 "parameter name not available" | javac 未加 `-parameters`，Spring @PathVariable 拿不到参数名 | 编译命令加 `-parameters` | code=200 ✓ |
| 3 | 移动端发消息"发送失败" | 前端传 `otherId`，后端要 `toId`；路径 `/messages/send` 后端是 `/messages` | 改参数名和路径 | code=200 ✓ |
| 4 | 聊天页没有输入框 | .page 用 flex:1 无固定高度，input-bar 被挤出屏幕 | 根节点 height:700px，chat-list height:500px | 输入框显示 ✓ |
| 5 | 老师消息显示在右侧 | UTS 中 `m['fromId'] == myId` 类型不匹配 | load 后逐条 `m.set('isMine', (fid as number)==this.myId)` | 方向正确 ✓ |
| 6 | toDouble 编译报错 | UTS 无此方法 | 改回 `as number` 强转 | 编译通过 ✓ |
| 7 | 删除已读把私信也删了 | deleteRead 没排除 type=4 | 加 `.ne(MessageEntity::getType, 4)` | 私信保留 ✓ |
